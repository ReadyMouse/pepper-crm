# templates — Email Templates

## Purpose

Tera HTML templates for the weekly CRM digest email. Used by `mcp-digest-server` (via `pepper-crm` / workspace `templates/` path).

## Contents

| File | Description |
|------|-------------|
| `digest.html` | Weekly email layout: pending tasks, due reconnects, Pepper branding |

## Preview

Run `pepper-web` and open `/preview`, or `pepper --dry-run` to see rendered output in logs.

## Open-source candidate

**Yes.** Plain HTML/Tera with no proprietary content.
